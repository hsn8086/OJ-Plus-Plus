# v2.1 极简重构变更日志

## 概述

v2.1 版本实现了**真正的极简图形化界面**，在保持所有功能完整的前提下，大幅简化了视觉和交互。

---

## 🎨 视觉改进

### 1. 导航优化
**之前**：
```
┌────────────────────────────────┐
│         Title              ✕   │
└────────────────────────────────┘
[← Back to list]  Providers  <--- 大文字按钮在内容区
```

**现在**：
```
┌────────────────────────────────┐
│ ← Title                    ✕   │ <--- 图标按钮在头部
└────────────────────────────────┘
```

- ✅ 返回按钮固定在面板头部左侧
- ✅ 使用图标（`←`）替代文字
- ✅ 标题随视图自动切换

### 2. 尺寸紧凑化

| 元素 | v2.0 | v2.1 | 变化 |
|------|------|------|------|
| 面板宽度 | 680px | 620px | -60px |
| 按钮高度 | 32px | 30px | -2px |
| 正文字号 | 13px | 13px | 不变 |
| 标签字号 | 12px | 11px | -1px |
| 按钮字号 | 12px | 11px | -1px |
| 元信息字号 | 11px | 11px | 不变 |
| 分段间距 | 12px | 10px | -2px |

### 3. 输入框统一

**之前**（视觉不平衡）：
```
Reasoning: [下拉框 ▼]
Reasoning Effort: [文本框____]  <--- 不一致
```

**现在**（视觉统一）：
```
Reasoning: [下拉框 ▼]
Reasoning Effort: [下拉框 ▼]  <--- 一致
```

## 🐛 Bug 修复

### 1. i18n 缺失
**问题**：很多翻译键直接显示为 `settings.name`、`settings.duplicate` 等。

**修复**：添加所有缺失的翻译键
```typescript
// zh.ts / en.ts
'settings.title': '设置' / 'Settings'
'settings.general': '通用' / 'General'
'settings.basic': '基础配置' / 'Basic'
'settings.behavior': '翻译行为' / 'Behavior'
'settings.language': '界面语言' / 'Language'
'settings.name': '名称' / 'Name'
'settings.manage': '管理' / 'Manage'
'settings.edit': '编辑' / 'Edit'
'settings.duplicate': '复制' / 'Duplicate'
'settings.delete': '删除' / 'Delete'
'settings.noProvider': '无提供商' / 'No providers'
'settings.noMatch': '无匹配结果' / 'No matches'
'settings.search': '搜索...' / 'Search...'
```

### 2. 功能缺失
**问题**：过度简化导致丢失重要功能。

**修复**：
- 恢复额外提示词输入框
- 恢复自动翻译开关
- 恢复超时和重试设置
- 恢复高级选项（headers, body）

### 3. 样式支持
**问题**：textarea 没有样式定义。

**修复**：
```css
.ojpp-panel textarea {
  height: auto;
  padding: 8px 10px;
  resize: vertical;
  font-family: ui-monospace, Menlo, monospace;
  font-size: 12px;
  line-height: 1.5;
}
```

## 🎯 设计原则（v2.1）

### 1. 极简图形化
- 少即是多：删除所有非必要文字
- 图标优先：按钮用图标而非文字
- 一目了然：用户不需要阅读就能操作

### 2. 视觉统一
- 所有同类元素高度一致
- 表单控件类型统一（尽量用下拉框）
- 颜色、间距、圆角使用设计 Token

### 3. 功能完整
- 不为了简化而删除功能
- 高级选项折叠而非删除
- 所有设置都可访问

### 4. 流畅动效
- 所有交互有即时反馈
- 进入/退出使用物理动画
- 错开动画增加层次感
